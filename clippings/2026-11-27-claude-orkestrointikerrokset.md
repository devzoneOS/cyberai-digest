## Keskeiset uutiset

- **Pääsessio ei kirjoita koodia.** Claude Code -pääsessio suunnittelee työn ja delegoi toteutuksen erillisissä Git-worktreeissä toimiville agenteille Herdrin kautta. Työnkulku tuotti 37 TestFlight-buildia viidessä päivässä aiemman yhdeksän sijaan.

- **AI-illuusio.** Puheentunnistuksen historian pohjalta essee näyttää viisi aluetta, joissa AI-lupaukset voivat ohittaa todisteet. Matkasuunnitelmakokeessa yksi agentti ylsi moniagenttijärjestelmien tasolle samalla laskentateholla.

- **Kuusi kerrosta tuotantoagenttiin.** Event-triggerit, tila, työkalut, luotettu konteksti, evaluaatio ja ajonaikainen hallinta; tila kannattaa tallettaa Postgresiin, deterministinen logiikka tyypitettyjen työkalujen taakse ja vaaralliset teot ihmishyväksyntään.

- **MCP-optimismi 2027.** Code Mode, asynkroniset tehtävät ja tapahtumat tekevät MCP:stä taas hyödyllisen, kun asiakkaat ketjuttavat työkalukutsuja kontekstin ulkopuolella ja levittävät pitkiä töitä agenteille.

- **Työkaluja.** Vite 8.4 tuo dev-palvelimen allowlistin ja päällekkäisten dev-palvelimien tunnistuksen, ja AWS Labsin CLI Agent Orchestrator ajaa Claude Code-, Kiro- ja Codex-agentteja rinnakkaisissa tmux-sessioissa.
