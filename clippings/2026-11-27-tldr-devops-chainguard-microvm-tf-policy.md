## Keskeiset uutiset

1. HashiCorp julkaisi yleisesti saataville HCL-pohjaisen tfpolicy-tuen Terraform Stacksille sekä usean käyttöönottoryhmän orkestroinnin ja agent-yhteensopivat CLI-komennot JSON-tulosteella. SCIM 2.0 -provisionointi yleistyi HCP Terraform Standard- ja Premium-suunnitelmissa.

2. Chainguard siirsi tuhansia päivittäisiä käännöksiään GitHub Actionsista omalle microVM-infrastruktuurilleen estääkseen julkaisujonojen junoutumisen pilvikatkosten aikana. CVE-korjausagentit toimivat 97-98 prosentin viikkotarkkuudella, ja pakettipäivitykset yhdistyvät automaattisesti noin 99 prosentissa tapauksista.

3. Octopus Deploy uudisti käyttöliittymänsä: instanssilaajoinen haku, ryhmitelty navigaatio ja selattava REST API -referenssi noin 1 800 päätepisteelle. Päivitys on Octopus Cloudissa ja saavuttaa itse isännöivät asiakkaat joulukuussa.

4. Katsauksessa perustellaan, milloin jaettujen Kubernetes-klustereiden sijaan kannattaa käyttää erillisiä klustereita: räjähdysydin, verkon ulottuvuus ja sääntelyrajat oikeuttavat erottelun, vaikka monistettavat komponentit nostavat kustannuksia.

5. Työkaluina esitellään stitch-skills (Agent Skills -avoin standardi) ja Docker Compose Linter, joka tarkistaa Compose-tiedostot virheiltä ja tukee automaattisia korjauksia sekä CI-integraatioita.
